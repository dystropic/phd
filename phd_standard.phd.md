# PHD
### PROP HANDSHAKE DOCUMENT STANDARD

```text

The Crucible Problem        human ↔ agent ↔ agent · model-language


document          one file · model language
representation    visual = text = semantic = relational = computational
economy           partial information · attention budget
constraints       local stays local · unresolved stays unresolved
```

---

A PHD does not need to contain everything another human or agent could know. The [constraints](#constraints) it does contain cannot silently become different relations while they cross the [handshake](#handshake).

That crossing happens through [model language](#model-language). Wording, order, omission, rhythm, markup, placement, repetition, density, and register are already part of the state being computed from. They are not presentation around it.

What stays out of the file is not automatically missing. Communication is [partial](#partial-information) from the start. The question is what the document still carries after another human or model reads it, and what changed because the document took this form rather than another.

A representation can get much smaller before anything consequential disappears. Keep going and a [compression limit](#compression) appears. Past it, another small reduction removes a relation whose absence opens a much larger field of search, reconstruction, disagreement, and downstream manufacture.

The same standard appears again as a [template](#template) and a [terminal wizard](#terminal-wizard). Neither gets a second ontology. The questions used to make a PHD and the page produced from those answers are inside the same crucible.

---

## The Crucible Problem

The silicon crucible problem starts while the crucible is being made.

A contaminant introduced there is already present before ultra-pure silicon arrives. Later purity does not recreate the crucible that should have existed. Downstream fabrication inherits the material state that actually exists.

Language sits that far upstream for a model.

A phrase enters the context. The model computes from that state. The result becomes code, another file, media, analysis, another prompt, another model context, a physical operation, or language another person works from. The farther the consequence travels, the harder it gets to recover where a false relation first entered.

That is why the PHD is one file in [model language](#model-language), not a human document that gets summarized into model language later. The summary would be another crucible.

---

## Model language

There is no detached representational state behind the computation carrying the untouched meaning.

The representation is the computational state.

Change `constrain` to `control` and the new word does not sit above the old relation as a synonym. If `control` brings a chooser, target, regulator, or authority into the state, the computation now has those relations available.

Write simultaneous pressure as a numbered sequence and the sequence is now present.

Write a possibility as an intention and intention is now present.

Write a local fact without its local binding and wider reach becomes easier to infer.

The page participates too. A heading changes what sits beneath it. Alignment puts language into relation. Whitespace separates. Repetition increases pull. A link changes what can be reached directly from a word already in the sentence.

The [visual representation](#page-architecture), text representation, semantic representation, relational representation, and computational representation do not get independent lives here.

They are the state.

## Constraints

Put a constraint into the file at the reach the situation gives it.

A local constraint stays local. A constraint that binds two relations does not become a general rule because the sentence sounds cleaner without its boundary. A constraint whose cause is unresolved does not acquire a cause because English wants one.

Several constraints can remain present together without being sorted into a sequence.

Their interaction does not need to be settled before another human or agent works from the file.

The PHD carries the constraint, not a promise that every consequence of the constraint has already been discovered.

A constraint written into the file can link directly to the language that bears on it elsewhere in the same document. The link belongs in the sentence where that relation already exists:

```markdown
This remains unresolved until the [thermal constraint](#thermal-constraint)
and the independent position reading stop disagreeing.
```

The link does not explain the relation. It lets the document be traversed through it.

What is unresolved stays unresolved until contact supplies the missing discrimination. That is not incomplete documentation. It is a constraint on what the document gets to invent.

## Partial information

Communication is partial by construction.

There is no complete state standing behind the file waiting to be copied over. A communicator selects, omits, repeats, places, names, leaves unnamed, returns to, and stops. Those differences give the communication its shape.

The budget is inherent.

A paragraph spends attention. So does a heading. So does a qualification. So does silence. Another sentence earns its cost when the relation it carries changes what another human or model can discriminate or compute from.

Economy of words does not mean miserly language.

Ten words that collapse a live relation are expensive.

A page that keeps several coupled constraints intact can be cheap.

The [compression problem](#compression) begins where shorter stops meaning less redundant and starts meaning less semantic structure.

---

## Compression

Higher-order structure compresses.

Redundancy disappears. Symmetry collapses. Repeated structure does not need to be carried again in full. A large state can become much smaller while the relations that matter remain available.

Then the leverage flips.

Another small reduction merges two states that needed to stay distinct. A dependency disappears. Timing collapses into order. Provenance falls away. An unresolved relation turns into a clean sentence.

The reduced file still reads well.

That is the bad part.

Language can remain locally coherent after the relation carrying the semantic value is gone. Downstream humans and agents then spend far more than the compression saved: infer the missing dependency, branch across several plausible readings, build incompatible implementations, reconcile them, add context, run tests, search history, write more language.

The first cheap reduction becomes the spawn point for the later cost.

PHD does not chase total representation to avoid that. Total representation loses before play starts. It keeps pressure on the leverage inversion point: what disappears harmlessly, and what disappearance changes the combinatorics of everything that follows?

That pressure returns to [partial information](#partial-information). The file stays partial. It does not pretend every unexpressed relation is residual, and it does not drag every vanishing residual into the file in pursuit of an ideal total.

---

## Handshake

Agreement is not evidence that the handshake held.

A human can say yes while the relation that matters remains unchanged. A model can repeat a correction perfectly and generate from the same bad state immediately afterward.

The agreement token proves that agreement language happened.

The handshake shows itself in what survives into the next computation.

A local constraint remains local. An unresolved relation remains unresolved. A distinction that mattered before the crossing still matters after it. A model does not need to invent a controller, actor, sequence, intention, category, or causal arrow to continue.

Different humans and agents do not need identical internal states.

They have the same file available to contest.

That difference matters. Consensus can hide divergence. Contestation exposes it.

The PHD does not settle the ensemble before the ensemble starts working. The frontmatter gives the high-leverage coordinate:

```text
human ↔ agent ↔ agent · model-language
```

The body carries the relations that need to survive contact inside that coordinate.

A second agent can read another part of the same file. A human can reject what both agents inferred. Another representation can expose that the first one changed the relation. The file remains the place those differences can meet without requiring a new total account every time they do.

---

## Page architecture

The page is not a display layer for the standard.

It is part of the standard.

The large `PHD` title dominates before any sentence begins. `PROP HANDSHAKE DOCUMENT STANDARD` binds the name to the document species without forcing a definition-first opening. `PHD-STD-001`, `REP 0.1`, `The Crucible Problem`, and `human ↔ agent ↔ agent · model-language` sit in a tighter register because they are coordinates, not prose.

The aligned frontmatter underneath them stays sparse. Each field gets expensive real estate because it changes how the body is read.

The body changes scale when the semantic scale changes.

Long prose holds several relations together when splitting them would destroy the relation. A short paragraph stops where another sentence would only repeat. Literal syntax appears in code form because changing the characters changes the material. Internal Markdown links sit on words already doing semantic work:

```markdown
[constraints](#constraints)
[handshake](#handshake)
[model language](#model-language)
[partial](#partial-information)
[compression limit](#compression)
[template](#template)
[terminal wizard](#terminal-wizard)
```

The links do not become a menu.

The prose remains readable straight through. Following a link changes the reading path without forcing the document into one sequence.

# `<situation>`

Write the local situation in plain model language.

Do not turn this opening into a summary of everything known. Put here what another human or agent needs before the constraints below can be read without inventing their relation.

## Constraints

Write the constraints at the reach they actually have.

A constraint can take a paragraph when its internal relation needs a paragraph. Several independent constraints do not need matching sentence shapes.

Use local Markdown links when another part of this PHD already carries material the constraint bears on.

```markdown
The output still depends on the [unresolved carrier relation](#carrier-relation).
```

Keep uncertainty in the sentence where it belongs. Do not collect every unknown into an `Unresolved` bucket unless the local PHD genuinely has such a relation.

## `<local heading when the situation earns one>`

The standard does not predeclare the rest of the document’s ontology.

Add a section because the material needs a stable place and name in this PHD, not because the template offers an empty slot.

The heading changes the state. Name it accordingly.

The wizard does not diagnose the situation for the user.

It asks for language whose answers can be written into the PHD without silently increasing their reach. It does not turn absence into an empty required section. It does not resolve disagreement to make the generated file cleaner. It does not invent an ensemble taxonomy beyond what the human actually names.

Its own prompts are part of the [language crucible](#the-crucible-problem). Changing those prompts changes the file it can produce.

The generated file returns to the same [handshake](#handshake), the same [constraints](#constraints), the same [partial information](#partial-information), and the same [compression](#compression) pressure as the standard that produced it.
